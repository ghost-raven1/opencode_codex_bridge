# Проверка 0.2.0 — 2026-10-10

## Текущее состояние

Удалён пакет `@codexbridge/companions`: нативное приложение, персонажи, ассеты, TTS, диктовка, анимации и связанные скрипты, тесты и CI-задача. Из API моста удалены снимки сообщений для озвучки. Поток текста, итоговый результат, `threadId`, отмена и запросы разрешений сохранены.

Генератор создаёт профили `quiet` и `jarvis`; запуск и сборка профиля по умолчанию используют `quiet`. Старый сгенерированный профиль удалён, оба оставшихся профиля обновлены.

`npm run setup:opencode` устанавливает глобальный плагин и провайдер. Обычный запуск `opencode` обнаруживает мост в любом проекте. Существующий JSONC, другие провайдеры и более строгие разрешения сохраняются; изменяемые файлы имеют резервные копии.

## Проверено в этом изменении

- Node **24.15.0**; `npm run check`: strict TypeScript, **46/46 Vitest в 8 файлах**, сборка `@codexbridge/opencode`.
- Контрактные проверки установщика: пути с пробелами, повторная установка, сохранение личных настроек и JSONC, явный и общий запрет разрешений.
- `npm run smoke:opencode`: реальный локальный профиль загрузил `codex`, `submit_plan`, TypeScript LSP и три субагента с наследуемой моделью и разрешениями.
- `npm run bundle:all`: оба профиля создаются без нативного пакета; устаревшие точки подключения отсутствуют.
- `npm run smoke:startup`: настоящий **OpenCode 1.3.2** из временного проекта без `OPENCODE_CONFIG` и `OPENCODE_CONFIG_DIR` загрузил глобальный инструмент `codex`, провайдер и `/codex`. Правило `codex_system` осталось `ask`; удалённый инструмент персонажей отсутствует.

Проверка запуска использует локальный сервер OpenCode и чтение его конфигурации/реестра инструментов. Запросы к модели не выполнялись. Результаты старых inference/MCP-проверок ниже относятся к прежнему состоянию.

Локальный кеш ранее скачанных TTS-моделей в `.local/tts/` сохранён; в текущей сборке он не используется. Пользовательские данные вне репозитория не удалялись.
