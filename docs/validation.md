# Проверка 2026-10-01

Рабочая ветка: `feature/opencode-codex-bridge`. Проверка выполнена на macOS arm64, Node 24.15.0, OpenCode 1.3.2. Git remote изначально отсутствует; публикация и CI на GitHub не выполнялись.

## Подтверждено локально

- TypeScript strict и сборка обоих CLI-плагинов.
- Vitest: 95 тестов в `tests/`; RPC framing, разрезанный UTF-8, раннее завершение, обрыв/некорректный протокол/переполнение, timeout/отмена, отказ и разрешение OS-доступа, ограничение проекта, продолжение и параллельные ходы, сопоставление ролей, дедупликация речи, границы приватного текста, обновление авторизации и браузерный вход через mock RPC.
- Настоящий OpenCode: `smoke:opencode -- --native` подтвердил инструменты `codex`, `companion`, `submit_plan`, правило `codex_system: ask` и TypeScript LSP. Нативный процесс проходит handshake; микрофон и озвучка ответов в этой проверке отключены. Запрос к модели OpenCode не вызывается.
- MCP SDK подключается по stdio к нашему MCP-серверу и установленному Jarvis; успешно получает списки инструментов.
- Настоящий TypeScript language server выдаёт TS2322 для ошибочного присваивания.
- Настоящий Codex App Server проходит handshake. Отдельный запрос к модели через локальный Codex **0.159.3** успешно возвращает `CODEXBRIDGE_OK`.
- Авторизация основного агента OpenCode проходит через RPC моста и существующий вход Codex. Пользовательский профиль выводит восемь моделей `codexbridge/*`; сохранена выбранная в Codex `gpt-6-astra`, короткие служебные запросы направлены в `gpt-5.6-luna`.
- `smoke:opencode -- --native --inference`: настоящий OpenCode с нативным плагином выполнил вызов `read` через `gpt-6-astra` и вернул точный случайный маркер из тестового файла. Это проверяет основной цикл OpenCode, авторизацию, Responses streaming и продолжение после результата инструмента.
- snip **0.25.2** установлен локально с проверкой SHA256 официального архива; `snip hook` действительно преобразует поддерживаемую git-команду.
- Нативное приложение с AVSpeechSynthesizer и Speech/AVAudioEngine собирается для macOS 13+ без предупреждений; ad-hoc подпись и Info.plist проходят проверку.
- Реальный системный голос Milena `ru-RU` проходит `--speech-test` без атласа: `start → 6 word callbacks → end`, exit 0. Отдельно проверены stop/cancel, mute и закрытие stdin. Физическое прослушивание человеком не подтверждено.
- Доставка диктовки проверена как вставка черновика без автоматической отправки, включая восстановление после сбоя, конкурентные попытки восстановления и явную ошибку переполнения.
- JSONL-канал нативного процесса проверен на разрезанном UTF-8, нескольких крупных соседних кадрах, выходе до handshake и повреждённом протоколе.
- Графика: все 16 кадров имеют настоящую прозрачность, голова и одежда точно восстанавливают исходные кадры; просмотрены 16 сочетаний. Нативный AppKit-снимок подтвердил масштаб и размещение четырёх персонажей без обрезания.
- Роли: русские и английские задания, приоритет явной настройки, подзадачи и реальный `sessionId` из metadata инструмента `task`; текст ответа не меняет роль. Основная сессия говорит при смене роли, дочерние сессии не озвучиваются.
- Нативная QA-копия: реальное перетаскивание за подпись переместило группу на `+300/+113` px. Правый клик скрывает персонажей, события задач не показывают их обратно; положение и скрытие сохраняются после перезапуска. Проверены `show` и `reset-position`.

## Найдено и исправлено

- Глобальный Codex 0.146.0 отклонил настроенную модель `gpt-6-astra` как требующую новую версию. Мост теперь использует локальную зафиксированную зависимость 0.159.3; выбор модели сохранён.
- OpenCode 1.3.2 объединял плагины по имени конечного файла, теряя bridge/plannotator/snip. У каждого создана отдельная точка входа с уникальным именем.
- Внутри OpenCode `process.execPath` указывает на исполняемый файл OpenCode со встроенным Bun. Запуск `codex.js` исправлен на Node; прежняя реализация работала при отдельном Node-запуске, но ломала авторизацию из плагина.
- Принудительное обновление токена после HTTP 401 больше не подхватывает обычное параллельное чтение старого токена. Повтор допускается только один раз; токены не записываются в конфигурацию OpenCode.
- LSP smoke-клиент изначально не объявлял capability `publishDiagnostics`; это исправлено, после чего реальная диагностика получена.
- Vitest по умолчанию подбирал тесты сторонних зависимостей из созданного OpenCode-кеша. Область тестирования ограничена собственным каталогом `tests/`.
- Первая версия фильтра речи оставляла обрывки Markdown-ссылок; порядок очистки исправлен и покрыт тестом.

## Ещё не подтверждено

- Микрофон, точность распознавания и воспроизведение на физических аудиоустройствах.
- Новый браузерный вход с ручным подтверждением аккаунта: используется существующая авторизация; текущая сессия пользователя не сбрасывалась. Наличие остальных моделей в каталоге не доказывает успешный запрос к каждой из них.
- Ручной диалог системного разрешения в терминале: отказ/подтверждение проверены на уровне транспорта и host callback, а наличие правила — в настоящем OpenCode.
- Отдельные переключатели очков/наушников/книг: сейчас они входят в два доступных слоя головы и одежды.
- Фонемная точность lip sync: нативный канал использует callbacks AVSpeechSynthesizer по словам. Внешние TTS отключены по выбору пользователя.
- Работа сборки на Windows/Linux, CI и установка на другой Mac. Нативный компаньон пока только macOS.

Успех unit-тестов, протокольных smoke-тестов и реального короткого ответа модели не означает, что весь пользовательский голосовой сценарий уже проверен.
