# Графический пак

Пользовательский референс: `assets/reference/team.png`. Исходная генерация ImageGen сохранена без изменений в `packages/companions/assets/source/team-generated-rgb.png`; тексты запросов — в `docs/imagegen-prompts.md`.

Шахматный фон удалён технической обработкой по поручению пользователя. Скрипт `scripts/prepare-sprites.py` выделяет нейтральный фон, сохраняет тёплые белые участки одежды, убирает отдельные точки и выравнивает шею и подошвы во всех кадрах. Он не рисует новые лица, одежду или скрытые под предметами части тела. Для повторной сборки нужны Python 3, Pillow и NumPy:

```sh
python3 scripts/prepare-sprites.py
```

## Контракт атласов

Все три PNG имеют настоящую прозрачность RGBA и одинаковые размеры **1024 × 1536**: 4 столбца × 4 строки, ячейка **256 × 384**. Масштабировать с сохранением пропорций **2:3** и без интерполяции. Координаты ниже идут от левого верхнего угла.

| Поле | Значение |
| --- | --- |
| Столбцы 0–3 | `lead`, `code`, `research`, `review` |
| Строки 0–3 | `idle`, `talking`, `blink`, `working` |
| Общая точка шеи | `(128, 120)` |
| Верх головы | около `y=24` |
| Линия подошв | `y=368` |
| Полный персонаж | `team-atlas.png` |
| Волосы, лицо, встроенные аксессуары головы | `head-atlas.png` |
| Одежда, руки, предметы в руках | `body-atlas.png` |
| Машиночитаемое описание и границы кадров | `atlas.json` |

Для конструктора нужно взять одинаковую строку состояния из `bodyColumn` и `headColumn`, сначала нарисовать тело, затем голову в том же прямоугольнике. При совпадающих столбцах результат побитово восстанавливает соответствующий кадр `team-atlas.png`. Разрез повторяет контуры волос и воротника, поэтому длинный хвост не обрубается горизонтальной полосой; поднятая рука исследовательницы остаётся частью тела. Поле `headSplitRatio` указывает высоту общей точки шеи, а не линию для обрезки слоёв.

Это **два слоя внешности**, которые дают 16 сочетаний головы и одежды. Очки, гарнитуры, наушники и предметы уже нарисованы поверх исходного персонажа: за ними нет изображения лица, рук или одежды. Поэтому отдельных переключателей этих аксессуаров пока нет. Для них нужен отдельно нарисованный набор слоёв с восстановленными скрытыми областями. Жест руки исследовательницы остаётся жестом поправления очков и при выборе другой головы.

## Визуальная проверка

- `packages/companions/assets/preview-dark.png` — все 16 кадров на тёмном фоне: фон прозрачен, белая одежда сохранена, подошвы не обрезаны.
- `packages/companions/assets/preview-combinations.png` — все 16 сочетаний головы и одежды в состоянии ожидания.
- Скрипт проверяет точное восстановление всех 16 исходных кадров из двух слоёв, отсутствие обрезания по бокам и создаёт контактные листы при каждой сборке.

Состояние `talking` — анимация открытого рта, переключаемая событиями речи. Это не набор фонем и не точная артикуляция. Источник — иллюстрация с пиксельной стилизацией; техническая обработка не преобразует её в заново нарисованный низкоразрешённый pixel art.

## Дополнительные позы и переходы

`poses.png` и `transitions.png` имеют размер **1024 × 1920**, по пять строк с теми же четырьмя ролями, ячейкой и точкой шеи. Контракт и SHA-256 — в `animation.json`.

| Атлас | Строки сверху вниз |
| --- | --- |
| poses.png | thinking, working_alt, success, waiting, error |
| transitions.png | idle_shift, blink_half, speech_half, blink_closed, speech_open |

Новые рисунки сделаны ImageGen по исходным персонажам. Исходники и запросы сохранены в `assets/source/`; техническая обработка удаляет фон и выравнивает кадры. В переходах выражение лица переносится на неизменное исходное тело: все пиксели ниже `y=118` совпадают с исходным idle. Последние две строки используют уже нарисованные опорные выражения. Это устраняет дрожание одежды при речи.

Нативный renderer использует позы по состоянию задачи, промежуточные фазы моргания и рта. Движение рта управляется амплитудой локального WAV либо событиями системного синтезатора. Расширенные цельные кадры применяются при совпадении головы и одежды; смешанные `seeded` сочетания сохраняют исходные два слоя. Изображения упаковываются в `Contents/Resources` при `companion:build`.

Проверочные листы: `poses-contact.png`, `transitions-contact.png`; последовательность состояний — `animation-preview.gif`. Повторная техническая подготовка (Pillow и NumPy) создаёт кандидаты в `.local/animation-study/`, не перезаписывая production-пак:

```sh
python3 scripts/prepare-animations.py
python3 scripts/stabilize-animations.py
```
