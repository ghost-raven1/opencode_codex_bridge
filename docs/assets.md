# Графика компаньонов 0.2.0

Текущая анимация послойная: тело, голова и мимика отрисовываются отдельно. Цельные рисунки больше не сменяют друг друга во время работы или речи. Это сохраняет силуэт одежды и положение предметов без скачков между позами.

Пользовательский референс — `assets/reference/team.png`; исходная генерация — `packages/companions/assets/source/team-generated-rgb.png`. Запросы ImageGen, исходники и регистрация сохранены. Скрипты выполняют разрешённую пользователем техническую обработку; новые детали одежды для смешанной внешности ранее дорисованы ImageGen.

## Рабочие слои

В `packages/companions/assets/` и нативном `Contents/Resources` используются шесть PNG:

| Файл | Назначение |
| --- | --- |
| `mixed-body-atlas.png` | Тело, одежда, руки и предметы; восстановлены участки под волосами |
| `mixed-head-atlas.png` | Голова, волосы и аксессуары головы |
| `facial-v3.png` | 18 отдельных накладок лица для каждой роли |
| `head-atlas.png`, `body-atlas.png` | Резервные исходные слои |
| `team-atlas.png` | Резервный цельный кадр |

Сетка базовых атласов — **1024 × 1536**, четыре столбца `lead`, `code`, `research`, `review`; ячейка **256 × 384**. Для непрерывной анимации берётся спокойная поза из строки 0. Остальные строки исходных слоёв сохранены для воспроизводимости. Общая точка шеи — **(128, 120)** от верхнего левого угла, подошвы — **y=368**. Геометрия описана в `atlas.json`.

Исправленная пара `mixed-*` используется и для пресетов, и для смешанных персонажей: заполненные участки под головой не открывают прозрачных дыр при её небольшом повороте. Исходные `head` + `body` побитово восстанавливают `team`. Очки, гарнитуры и наушники относятся к голове; руки, книга и планшеты — к телу. Независимых костей для рук, волос или предметов пока нет.

`LayeredMotion.swift` задаёт непрерывное дыхание, небольшой поворот и сдвиг головы; состояние задачи меняет характер редкого жеста. Интервал жестов каждого персонажа — **8–15 секунд**, длительность — **3.6 секунды**. Моргание имеет независимый нерегулярный интервал **2.3–5.8 секунды**. Тело и голова не переключаются на рисунки с другой геометрией.

Появление длится **1.2 секунды**, смена роли — **1.4 секунды**, уход — **450 мс**. При повторной смене применяется последняя назначенная внешность. В режиме системного уменьшения движения смещения выключены, переход заменён коротким проявлением **150 мс**. Пустая или скрытая группа останавливает таймер перерисовки.

## Мимика и края

`facial-v3.png` — **1024 × 6912**, четыре столбца и 18 строк:

| Строки | Содержание |
| --- | --- |
| 0–7 | Закрытый рот, небольшое открытие и шесть дополнительных форм речи |
| 8–13 | Шесть фаз моргания |
| 14–17 | Улыбка, беспокойство, сосредоточенность, удивление |

Накладки зарегистрированы внутри исходного лица, композятся с головой и двигаются вместе с ней. Амплитуда WAV или события системного синтезатора управляют открытием рта; это не распознавание фонем. Формы речи переключаются до четырёх раз в секунду.

`SpriteCache.swift` смягчает только узкую полосу альфа-контура примерно на один физический пиксель экрана. Внутренние пиксели сохраняются; подготовленные слои и лицевые комбинации кешируются. Размытие не выполняется для каждого кадра движения.

Подписи ролей — постоянные AppKit-контролы. Создание словаря шрифтов и `NSString.draw` убраны из кадрового цикла: на macOS 27 beta два отчёта об аварии указывали на этот путь CoreText.

## Очистка однослойных примеров

По запросу пользователя удалены старые цельные клипы V2/V3, их исходные покадровые генерации, сборщики и локальные превью, включая `.local/animation-study`. Удалено **124 файла, 123.64 МиБ**. Они больше не занимают место в рабочем дереве; ранее закоммиченные версии доступны в истории Git.

Все шесть рабочих PNG остались побитово прежними. Базовый рисунок `team-atlas.png` нужен как исходник разделения на голову и тело и резервный статический кадр; это не демонстрация покадровой анимации. Источники исправленных слоёв, регистрация и 72 накладки лица сохранены. Непрерывные положения слоёв не считаются новыми нарисованными позами.

`source/animation-v3/` теперь содержит только материалы мимики: исходные лица, запросы, зарегистрированные накладки и опорные точки. `scripts/assemble-faces.py` собирает лицевой слой независимо от удалённых цельных клипов. Превью текущего renderer находятся в `.local/companions-snapshots/`; при сборке bundle включаются только используемые изображения.

## Повторная подготовка и проверка

Нужны Python 3, Pillow и NumPy. Базовые и исправленные слои:

```sh
python3 scripts/prepare-sprites.py
python3 scripts/prepare-layered-bodies.py
```

Актуальный лицевой атлас:

```sh
python3 scripts/assemble-faces.py
```

Сборка и проверки реального renderer:

```sh
npm run companion:build
npm run test:native
npm run smoke:companions -- --visual --scale=1
npm run smoke:voice
```

Vitest проверяет уникальность 72 накладок, их границы и восстановленный рукав CODE. Native-тесты проверяют ограниченные непрерывные движения, мимику, уменьшение движения, устойчивые подписи и независимость облачка от звука. PNG реального окна сохраняются в `.local/companions-snapshots/`; результаты и границы проверки — в `docs/validation.md`.
