# Графический пак

Пользовательский референс: `assets/reference/team.png`.

Атлас: `packages/companions/assets/team-atlas.png`. Создан встроенным ImageGen на основе референса. Две генерации сохранили шахматную подложку в RGB вместо настоящей прозрачности; второй вариант восстановил нижние кадры. В текущем виде этот файл не готов для прозрачного desktop-overlay. Нужны удаление фона, выравнивание четырёх строк и проверка переключения кадров. Для технической обработки кодом запрошено явное указание пользователя.

Предполагаемый контракт: четыре роли по столбцам (lead, code, research, review), четыре состояния по строкам (idle, talking, blink, working); единый размер ячейки, одинаковые опорные точки внутри каждого персонажа. Изображение не заменяет ещё не реализованный послойный конструктор внешности.

Тексты запросов ImageGen сохранены в `docs/imagegen-prompts.md`.
