# Графика компаньонов 0.2.0

Текущая анимация послойная: тело, голова, руки, предметы и мимика отрисовываются отдельно. У каждого персонажа есть три базовые позы и 16 дополнительных рабочих/танцевальных рисунков со своими слоями. Новые повороты и смены танцевальных поз сохраняют видимость силуэта; внутри позы движение непрерывное. Контракт и ограничения новых рисунков — в [choreography.md](choreography.md).

Пользовательский референс — `assets/reference/team.png`; исходная генерация — `packages/companions/assets/source/team-generated-rgb.png`. Запросы ImageGen, исходники и регистрация сохранены. Скрипты выполняют разрешённую пользователем техническую обработку; новые детали одежды для смешанной внешности ранее дорисованы ImageGen.

## Рабочие слои

В корне `packages/companions/assets/` сохраняются шесть базовых PNG для резервного рендера при недоступном риге:

| Файл | Назначение |
| --- | --- |
| `mixed-body-atlas.png` | Тело, одежда, руки и предметы; восстановлены участки под волосами |
| `mixed-head-atlas.png` | Голова, волосы и аксессуары головы |
| `facial-v3.png` | 18 отдельных накладок лица для каждой роли |
| `head-atlas.png`, `body-atlas.png` | Резервные исходные слои |
| `team-atlas.png` | Резервный цельный кадр |

Сетка базовых атласов — **1024 × 1536**, четыре столбца `lead`, `code`, `research`, `review`; ячейка **256 × 384**. Для непрерывной анимации берётся спокойная поза из строки 0. Остальные строки исходных слоёв сохранены для воспроизводимости. Общая точка шеи — **(128, 120)** от верхнего левого угла, подошвы — **y=368**. Геометрия описана в `atlas.json`.

При доступных ригах смешанная внешность собирается из новой головы одного персонажа и тела другого с совмещением по измеренному pivot шеи. Руки и предметы остаются отдельными слоями выбранного наряда. Переносимые задние волосы `hair-back` отрисовываются перед телом, передние волосы и лицо — после. Пара `mixed-*` остаётся fallback: заполненные участки под головой не открывают прозрачных дыр при её небольшом повороте. Исходные `head` + `body` побитово восстанавливают `team`.

## Семь ригов с руками и предметами

`expansion/manifest.json` задаёт canvas 256×384, порядок слоёв, родителя, pivot, ограничение угла, лицевой атлас и длительности. Координаты идут от верхнего левого угла. Семь стоячих ригов содержат **40 рабочих PNG** и 126 лицевых накладок. Дополнительные 14 ригов в `expansion/poses.json` содержат **87 PNG** и ещё 252 накладки: по 18 для каждой позы. Эти базовые ресурсы дополняются 112 ригами в `expansion/choreography.json`. Профильные лица имеют `neutralOnly` и не декодируют пустой лицевой атлас. Исходники, QA и голосовые образцы не копируются в нативный Resources.

| Риг | Независимые части | Рабочие действия |
| --- | --- | --- |
| lead | Тело, голова, две руки, планшет | Касание и перелистывание планшета |
| code | Тело, голова, задние волосы, две кисти, ноутбук | Попеременная работа кистей на клавиатуре |
| research | Тело, голова, руки, книга | Чтение строки и движение у страницы |
| review | Тело, голова, руки, планшет | Отметка проверки и осмотр планшета |
| designer | Тело, голова, руки со стилусом и палитрой, коса | Штрих стилусом и проверка палитры |
| devops | Тело, голова, рука на поясе и рука с прибором | Проверка прибора и поправка щупа |
| tester | Тело, голова, руки с контроллером | Два ритма проверки контроллера |

LEAD, CODE, RESEARCH и REVIEW используют новый рисунок `source/core-v2.png`: взрослые пропорции согласованы с TESTER v2, при этом сохранены разные лица, причёски, одежда и рабочие предметы. ImageGen отдельно дорисовал скрытую одежду под руками, предметами и волосами; используются только закрытые ими участки. Голова, руки и предмет по-прежнему независимы. Старые 72 нарисованные формы мимики зарегистрированы по новым глазам и рту; нейтральный рот и открытые глаза взяты из нового рисунка, брови и оправа очков не подменяются старой геометрией. `WorkMotion.swift` задаёт 14 клипов с ограниченными углами и смещениями до 1,5 исходного пикселя. Танец по музыкальному ритму подавляет рабочие жесты пропорционально своей интенсивности. При Reduce Motion оба вида движения отключаются.

Три новые героини отличаются силуэтами, одеждой и предметами: коралловая коса и длинный асимметричный фартук DESIGN, синий undercut и рабочий комбинезон OPS, рыжая стрижка, очки, короткая жёлтая куртка и контроллер TEST. Новая TESTER v2 нарисована через ImageGen с отдельными исходниками мимики и участков одежды под руками; её нейтральное лицо берётся непосредственно из основного рисунка. Старые TESTER v1 и три несовместимых лицевых листа удалены, история сохранена в Git.

Для всех семи ригов одна равномерная трансформация сохраняет пропорции всего исходного рисунка. Прежнее раздельное масштабирование по горизонтали и по вертикали головы/тела расширяло тело более чем на 30%. Измеренные pivot каждого слоя определяют положение суставов; `(128,120)` относится только к старым резервным атласам. Поле `registration` в manifest хранит источник, единый масштаб и смещение; у базовой четвёрки `sourceRect` задаёт колонку общего исходника. Стопы остаются на общей линии `y=368`.

Хвост CODE вынесен в `hair-back`: слой следует голове, но рисуется за одеждой. ImageGen восстановил только участок волос, скрытый исходным ноутбуком. Фиолетовые плечо, воротник и рукав остаются в теле; смешанная внешность больше не переносит их вместе с головой. Отдельная регрессия проверяет принадлежность этих пикселей, наушники и восстановленный участок хвоста.

`prepare.py`, `prepare_faces.py`, `prepare_core.py` выполняют техническую регистрацию разрешённых пользователем материалов. Последний скрипт также вызывает `prepare_core_faces.py`. Повторное создание лица начинают с чистых слоёв, затем собирают накладки. Все текущие исходники имеют настоящую прозрачность; RGB и почти прозрачный шум вне силуэта обнуляются. Устаревшая подложка `core-underpaint.png` заменена двумя согласованными подложками v2.

`LayeredMotion.swift` задаёт непрерывное дыхание, небольшой поворот и сдвиг головы; состояние задачи меняет характер редкого жеста. Интервал жестов каждого персонажа — **8–15 секунд**, длительность по умолчанию — **3.6 секунды**. Моргание имеет независимый нерегулярный интервал **2.3–5.8 секунды**. Голова и мимика следуют геометрии выбранной позы.

`PoseAnimation.swift` чередует стоячую и сидячую работу через **30–50 секунд**, независимо для каждого агента. В состоянии отдыха полулежачая поза доступна через **3 секунды**; речь откладывает её, работа и танец возвращают стоячую позу. Смена позы длится **800 мс**, с Reduce Motion — **150 мс**. `expansion/poses.json` использует тот же контракт, что и основной manifest; PNG загружаются и кешируются по мере использования. Смешанная внешность меняет позу только при наличии корректных ригов для обеих составляющих. Источники, регистрация и ограничения — в [poses.md](poses.md).

Появление длится **1.65 секунды**: сбор частиц у ног, проявление снизу вверх и мягкое выравнивание. Смена роли — поворот и цветовая вспышка за **1.4 секунды**, уход — поклон и растворение за **900 мс**. После завершения задачи и всей речи персонаж остаётся ещё **30 секунд**. Возобновление работы плавно отменяет уход. При повторной смене применяется последняя назначенная внешность. В режиме системного уменьшения движения смещения выключены, переход заменён коротким проявлением **150 мс**. Пустая или скрытая группа останавливает таймер перерисовки.

## Мимика и края

`facial-v3.png` — **1024 × 6912**, четыре столбца и 18 строк:

| Строки | Содержание |
| --- | --- |
| 0–7 | Закрытый рот, небольшое открытие и шесть дополнительных форм речи |
| 8–13 | Шесть фаз моргания |
| 14–17 | Улыбка, беспокойство, сосредоточенность, удивление |

Накладки зарегистрированы внутри исходного лица, композятся с головой и двигаются вместе с ней. Амплитуда WAV или события системного синтезатора управляют открытием рта; это не распознавание фонем. Формы речи переключаются до четырёх раз в секунду.

`SpriteCache.swift` смягчает только узкую полосу альфа-контура примерно на один физический пиксель экрана. Внутренние пиксели сохраняются; подготовленные слои и лицевые комбинации кешируются. Размытие не выполняется для каждого кадра движения.

`SpriteDepth.swift` при загрузке готовит мягкие тени головы, рук и предметов с непрозрачностью до 24%. Они следуют трансформациям своих слоёв и рисуются только внутри альфа-маски тела, поэтому прежняя тень не остаётся на месте после движения руки. Кешированная тень под ногами имеет максимум около 20% непрозрачности, слегка меняет ширину при повороте и сохраняет контакт с землёй.

Округлая светотень рассчитывается по форме непрозрачных участков. Три направления света ограничивают число кешированных вариантов; исходная альфа, чёрные контуры и нарисованные детали сохраняются. `SpriteCache.swift` освещает голову после наложения рта/век, чтобы мимика не выделялась плоским пятном. Вместо сброса всего кеша при заполнении удаляется только давно не использованный кадр; максимум остаётся 512 изображений. Небольшое перспективное сжатие и наклон вокруг неподвижного сустава отделяют передние слои от корпуса. Предмет использует опору ближайшей руки; смешанная голова сохраняет собственную геометрию и точку шеи. Reduce Motion выключает перспективное движение, сохраняя статическую светотень. Это 2.5D-композиция исходных рисунков, без новых нарисованных кадров или трёхмерной модели.

`CharacterView.draw` перед каждым проходом очищает dirtyRect через `.copy`: без этого в прозрачном окне накапливались прошлые положения головы, волос и частиц.

Подписи имён и ролей — постоянные AppKit-контролы. Имя нового вызова агента показано крупнее, роль — рядом меньшим шрифтом; полное имя также доступно в tooltip. Создание словаря шрифтов и `NSString.draw` убраны из кадрового цикла: на macOS 27 beta два отчёта об аварии указывали на этот путь CoreText.

## Очистка однослойных примеров

По запросу пользователя удалены старые цельные клипы V2/V3, их исходные покадровые генерации, сборщики и локальные превью, включая `.local/animation-study`. Удалено **124 файла, 123.64 МиБ**. Они больше не занимают место в рабочем дереве; ранее закоммиченные версии доступны в истории Git.

Все шесть базовых PNG остались побитово прежними. Базовый рисунок `team-atlas.png` нужен как исходник разделения на голову и тело и резервный статический кадр; это не демонстрация покадровой анимации. Источники исправленных слоёв, регистрация и 72 накладки лица сохранены. Непрерывные положения слоёв не считаются новыми нарисованными позами.

`source/animation-v3/` теперь содержит только материалы мимики: исходные лица, запросы, зарегистрированные накладки и опорные точки. `scripts/assemble-faces.py` собирает лицевой слой независимо от удалённых цельных клипов. Превью текущего renderer находятся в `.local/companions-snapshots/`; при сборке bundle включаются только используемые изображения.

## Повторная подготовка и проверка

Нужны Python 3, Pillow и NumPy. Базовые и исправленные слои:

```sh
python3 scripts/prepare-sprites.py
python3 scripts/prepare-layered-bodies.py
```

Актуальный лицевой атлас:

```sh
python3 scripts/assemble-faces.py
```

Сборка и проверки реального renderer:

```sh
npm run companion:build
npm run test:native
npm run smoke:companions -- --visual --scale=1
npm run smoke:voice
```

Vitest проверяет лицевые накладки, прозрачные края, фактические пропорции всех семи ригов, сохранение нового нейтрального лица и зрачков в состоянии focus. Native-тесты проверяют ограниченные непрерывные движения, родительские трансформации, 28 рабочих и 28 спокойных клипов, очереди командных действий, мимику, уменьшение движения, очистку прозрачного кадра, сохранение альфы при добавлении объёма, устойчивые подписи и независимость облачка от звука. `npm run qa:motion` снимает промежуточные фазы AppKit в `.local/animation-qa/`, включая взаимодействия, речь, светлый/тёмный фон, три позы и масштабы 50–200%; проверяет сохранность исходных PNG по SHA-256. Звук и микрофон не включаются. PNG реального окна сохраняются в `.local/companions-snapshots/`; результаты и границы проверки — в `docs/validation.md`.
