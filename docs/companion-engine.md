# Контракт движка компаньонов

Версия сборки — `0.2.0`, версия ригов и клипов — `1`. Нативный рендерер,
регрессионные тесты и визуальные проверки собираются из общего списка
`scripts/lib/native-sources.mjs`. Новый компонент рендера добавляется туда;
отдельные нативные тесты используют `nativeTestSources` для малых зависимостей.

## Риги и регистрация

`AnimationContract.swift` задаёт исходный холст 256×384, координаты сверху вниз,
baseline стоп 368 и 18 лицевых состояний. Все слои остаются полноразмерными PNG
с прозрачностью; размеры окна применяются равномерно ко всему персонажу.
Тело — корень, голова следует телу, остальные слои привязаны к телу или голове.
Смешанные образы совмещаются по суставу шеи и используют позу, доступную обеим
частям. Чужая фронтальная мимика не накладывается на нейтральные ракурсы.

Пути ассетов относительные: без пустых сегментов, `.` и `..`, начального `/`
и обратных слешей. Необязательные позы загружаются лениво; ошибочные PNG
запоминаются как недоступные и повторно не декодируются на каждом кадре.
Перезагрузка библиотеки сбрасывает подготовленные изображения и расписания поз.
Послойная графика рисуется самостоятельно: старые общие атласы используются
как резерв и не являются обязательным условием для отображения рига.

## Длительности клипов

Источник авторских длительностей — `clips` в `assets/expansion/choreography.json`.
Он формируется командой `npm run assets:choreography`. `PoseRigLibrary` передаёт
проверенные настройки в `PoseAnimation`; значения не дублируются в контроллере.

| Клип | Поля | Текущие значения |
| --- | --- | --- |
| Работа | `holdSeconds`, `turnSeconds`, `settleSeconds` | 8–14 с, 0.3 с, 0.55 с |
| Танец | `beatsPerPose`, `transitionSeconds` | 2 удара, 0.22 с |
| Ходьба | `stepSeconds`, `durationSeconds`, `transitionSeconds` | 0.65 с, 2.6 с, 0.22 с |

Длительности конечные и положительные, границы удержания упорядочены, делитель
ритма ненулевой. Фазы ходьбы — `contact`/`passing`, направление рисунков — `right`;
персонажи используют свои отдельные танцевальные последовательности.
Ошибочный необязательный manifest исключается целиком: основная стоячая графика
и старые корректные позы остаются доступны. Старые файлы без `clips` получают
совместимые значения `ChoreographyClips.standard`; прежняя ходьба без собственного
`transitionSeconds` наследует длительность перехода танца. Тест сверяет стандартные
значения с реальным атласом, чтобы изменения формата не расходились со Swift.

## Идентичность и кеш

Расписание поз принадлежит образу и `invocationId`. Новый вызов того же агента
начинается со стоячей позы и новым расписанием; повторная metadata и compaction
с сохранённым ID продолжают текущую анимацию. Смена роли во время речи сохраняет
исходящий образ до середины перехода и возвращает ему фронтальную мимику.

Ключ подготовленного изображения типизирован: источник, размер сетки, кадр,
маска лица, радиус края и освещение. Запись удерживает исходные `NSImage`, пока
кешируется результат, поэтому повторный адрес объекта не подменяет спрайт.
Кеш ограничен 512 записями и 64 MiB подготовленных пикселей; при вытеснении
используется LRU. Более крупный кадр рисуется без кеширования. Это бюджет готовых
кадров, а не ограничение всей памяти процесса.

## Проверка изменений

`npm run check` проверяет TypeScript, Vitest и сборку пакетов.
`npm run test:native` проверяет контракт, подмену адресов изображений, бюджет/LRU,
смену вызова, переходы, мимику, очереди и Reduce Motion.
`npm run qa:choreography` использует тот же рендерер на светлом/тёмном фоне,
в трёх масштабах и смешанных образах; проверяет неизменность исходных PNG.
После `npm run companion:build` выполняется `npm run smoke:companions -- --visual`.
Эти проверки изолированы от пользовательского OpenCode; звук и микрофон выключены.
