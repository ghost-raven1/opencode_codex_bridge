# Лицевые слои

Здесь сохранены исходные лица ImageGen, их запросы и зарегистрированные прозрачные накладки. У каждой роли 18 выражений: восемь форм рта, шесть фаз моргания и четыре эмоции. `registration.json` описывает только лицевые опорные точки и маски.

Цельные покадровые примеры, их генерации и старые сборщики удалены по запросу пользователя. Собрать рабочий `facial-v3.png` из сохранённых накладок:

```sh
python3 scripts/assemble-faces.py
```

Геометрию тела и головы задают отдельные слои, а движение — `LayeredMotion.swift`.
