# Исходные ключевые позы

Здесь сохранены прежние цельные рисунки: 60 уникальных поз на каждую героиню, их манифесты и более ранние poses/transitions. Нативное приложение их не загружает: персонажи теперь собираются из независимых слоёв тела, головы и мимики.

Эти изображения остаются исходниками для дальнейшей работы, а не резервным режимом покадрового воспроизведения. Манифесты v2/v3 и Vitest проверяют уникальность и границы рисунков. `facial-v3.png` находится в корне `assets/` и используется приложением.

`prepare.py` из `source/animation-v2/` и `scripts/assemble-animations-v3.py` сохраняют цельные атласы сюда. Контактные листы и GIF — в `.local/artwork-previews/`, вне пакета и Git.
