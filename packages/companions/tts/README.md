# Локальная речь Qwen3-TTS

Синтез выполняется на Apple Silicon, без API-ключей и отправки текста. Один постоянный Python-процесс обслуживает все роли. Голоса `Serena`, `Vivian`, `Sohee`, `Ono_Anna` подтверждены в конфигурации модели; язык генерации явно задан как `Russian`.

Версии и ревизия модели находятся в `model.json`, полный список Python-зависимостей закреплён в `requirements.txt`. Модель Qwen3-TTS распространяется под Apache-2.0; MLX Audio — MIT. Установка загружает публичные пакеты и веса, дальнейший worker работает с `HF_HUB_OFFLINE=1` и `TRANSFORMERS_OFFLINE=1`.

## Установка и запуск

Нужны Apple Silicon, macOS 26+ для закреплённого MLX 0.32.3 и Python 3.12. На проверенной машине использован Python 3.12.14 из существующего Codex runtime. Глобальные Python-пакеты не меняются.

```sh
node scripts/setup-local-tts.mjs
.local/tts/.venv/bin/python -u packages/companions/tts/worker.py
```

Если Python 3.12 не обнаружен, укажи путь через `CODEXBRIDGE_TTS_PYTHON`. Веса, виртуальная среда и кеши библиотек находятся в `.local/tts/` и не входят в Git. Временные WAV сохраняются в отдельный закрытый каталог каждого worker внутри `~/Library/Caches/CodexBridge/audio/`: нативному приложению не нужен доступ к Documents для воспроизведения. Установка занимает примерно 2.9 ГБ с зависимостями и кешем.

## Протокол

После загрузки worker выдаёт `ready` с полями `model`, `revision`, `voices`, `sampleRate`, `loadSeconds`. Вход — одна JSON-строка:

```json
{"id":"reply-1","text":"Привет, Алексей. Задача в работе.","voice":"Serena"}
```

Допустимы `text` длиной 1–2000 символов и необязательные `instructions` до 500 символов. Имена голосов нечувствительны к регистру. Ответ `audio` содержит `id`, абсолютный `path`, `duration` в секундах, `sampleRate`, `elapsedSeconds`, `peakMemoryBytes`. Ошибки возвращаются как `error` с `id`, безопасными `code` и `message`. Пользовательский текст не включается в диагностику.

stdout содержит только JSONL; сообщения библиотек уходят в stderr. Результат — mono PCM16 WAV 24 кГц. Плеер удаляет `speech-*.wav` после воспроизведения или отмены; `LocalTts` удаляет собственный каталог после завершения worker. Закрытие stdin завершает процесс; принудительная отмена выполняется владельцем процесса.

`LocalTts` в `src/local-tts.ts` запускает worker лениво, передаёт ему абсолютный каталог через `CODEXBRIDGE_TTS_AUDIO_DIR`, ограничивает ожидание старта 90 секундами и запросов 120 секундами. Он проверяет реальное расположение WAV, включая символические ссылки, и принимает файлы только из каталога текущего worker. Перезапуск получает новый каталог; очистка старого процесса не затрагивает новый. Явный `audioDirectory` сохраняет каталог под управлением вызывающей стороны. Очередь реплик сериализует вызывающая сторона.

## Измерения

Проверено 2026-10-01 на MacBook Pro, M1 Pro, 16 ГБ, macOS 27.0. Общая тестовая фраза: «Привет, Алексей. Задача в работе, скоро покажу результат.» Короткие реплики генерируются целиком до начала воспроизведения.

| Голос | Длительность WAV | Генерация |
| --- | ---: | ---: |
| Serena, первый запуск | 5.60 с | 10.57 с |
| Vivian | 5.20 с | 4.02 с |
| Sohee | 7.20 с | 4.34 с |
| Ono_Anna | 4.80 с | 3.09 с |
| Serena, повтор | 5.60 с | 3.23 с |

Первичная загрузка с холодным кешем заняла 22.76 с; следующий процесс загрузил модель за 4.93 с. Пик MLX на этих образцах — 5.73 ГБ (5.34 ГиБ); RSS процесса отдельно — 548 МиБ и не отражает всю память Metal. Дополнительный образец с инструкцией стиля достиг 6.56 ГБ MLX. Эти результаты относятся к коротким фразам; длинные ответы требуют больше времени и памяти. Краткие инструкции предпочтительнее до прослушивания результата.

Все четыре WAV созданы и проверены структурно. Метрики не заменяют оценку произношения и тембра пользователем. Версия 0.6B не загружалась: 1.7B показала приемлемое время после загрузки, поэтому дополнительное скачивание пока не требуется.

Для повторения измерений:

```sh
.local/tts/.venv/bin/python packages/companions/tts/benchmark.py
```

Полные показатели и абсолютные пути образцов сохраняются в `.local/tts/benchmark.json`. Образцы `sample-*.wav` остаются в отдельном каталоге запуска внутри `~/Library/Caches/CodexBridge/audio/`.
